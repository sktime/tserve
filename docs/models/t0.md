# t0

T0 from The Forecasting Company, plus every [`hub`](hub.md) model.

| extra | CPU tag | GPU tag | families | models | example |
| --- | --- | --- | --- | --- | --- |
| `t0` | [`:t0`](https://hub.docker.com/r/sktime/tserve/tags?name=t0) | [`:t0-gpu`](https://hub.docker.com/r/sktime/tserve/tags?name=t0-gpu) | T0 | 1 | `t0` |

!!! note "License"

    The registry crafts T0 with `license_accepted=True`. The checkpoint is gated. Accept the [model card](https://huggingface.co/theforecastingcompany/t0-alpha) and set a [Hugging Face token](../server/docker.md#hugging-face-token) before the first load.

## Start a server

=== "Docker"

    ```bash
    docker run --rm -p 8000:8000 sktime/tserve:t0 t0
    ```

=== "uv"

    ```bash
    uv pip install "tserve[server,t0]"
    ```

    ```bash
    uv run tserve t0
    ```

=== "pip"

    ```bash
    pip install "tserve[server,t0]"
    ```

    ```bash
    tserve t0
    ```

Check what loaded:

```bash
curl -s http://127.0.0.1:8000/models
```

## Predict

Python needs the [`client`](../client/python.md#install) extra on the caller.

=== "bash / zsh"

    ```bash
    curl -s http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d '{
      "past": {
        "timestamp": ["2024-01-01", "2024-01-02", "2024-01-03", "2024-01-04", "2024-01-05"],
        "sales": [120, 135, 128, 142, 138]
      },
      "time": "timestamp",
      "target": ["sales"],
      "fh": 3,
      "model": "t0"
    }'
    ```

=== "PowerShell"

    ```powershell
    curl.exe -s http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d '{"past":{"timestamp":["2024-01-01","2024-01-02","2024-01-03","2024-01-04","2024-01-05"],"sales":[120,135,128,142,138]},"time":"timestamp","target":["sales"],"fh":3,"model":"t0"}'
    ```

=== "Python"

    ```python
    from tserve.client import Client

    past = {
        "timestamp": ["2024-01-01", "2024-01-02", "2024-01-03", "2024-01-04", "2024-01-05"],
        "sales": [120, 135, 128, 142, 138],
    }

    with Client("http://127.0.0.1:8000") as client:
        result = client.predict(
            past=past,
            time="timestamp",
            target=["sales"],
            fh=3,
            model="t0",
        )
    print(result.predictions)
    ```
